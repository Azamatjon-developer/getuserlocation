📍 Get User Location

A simple and practical web application that detects the user’s geographic location using the browser’s Geolocation API and displays useful location data in a clean and user-friendly interface.

🚀 Live Demo

https://getuserlocation.vercel.app/index.html

🧠 Features

📌 Detects user’s current location

🌍 Shows latitude and longitude

🏙 Displays city and country (if API is used)

🔒 Requests user permission before accessing location
